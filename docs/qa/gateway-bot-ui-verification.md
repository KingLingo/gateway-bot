# Gateway Bot UI 验收记录

## 验收范围

- 视口：`1440x900`、`1024x768`、`390x844`、`360x800`。
- 主题：深色为默认验收主题；浅色通过首页切换后复查公开与认证流程。
- 公开流程：首页、登录、注册、找回密码、API Key 用量查询和权限重定向。
- 用户流程：首页、订阅、购买、密钥、用量、兑换、邀请、渠道、资料和订单。
- 管理流程：首页、运维、审计、用户、分组、渠道、账户、订阅、公告、代理、兑换码、
  优惠码、设置、风控、提示词审计、用量、邀请返佣与支付订单。
- 组件状态：导航、表格、筛选器、分页、表单、空状态、加载状态、错误状态和弹窗。

## 自动检查

```bash
cd frontend
pnpm run test:e2e:visual
```

默认运行全部公开流程。认证流程需要提供只读验收账号生成的 Playwright 状态文件：

```bash
E2E_BASE_URL=https://gateway.bot.cd \
E2E_STORAGE_STATE=/secure/path/gateway-bot-auth.json \
pnpm run test:e2e:visual
```

套件对每个页面检查：

- 页面宽度不超过视口，禁止横向溢出。
- 所有图片完成加载且有有效自然宽度。
- 页面不出现用户可见的 `Sub2API` 或上游仓库文案。
- 页面没有被权限守卫意外送回登录页。
- 为每条路由附加当前视口截图，失败时保留 trace 与截图。

## 生产验收门禁

发布产物部署到 `gateway.bot.cd` 后，必须使用真实只读账号运行认证路由矩阵，并人工复查
`/dashboard`、`/subscriptions`、`/keys`、`/usage`、`/admin/dashboard`、`/admin/users`、
`/admin/groups`、`/admin/accounts` 和 `/admin/settings`。任一页面出现旧品牌、横向溢出、
空白图片、不可读文本或控制台资源错误，立即执行 release 文档中的 rollback。
